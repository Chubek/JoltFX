# Application Input

Proposed Ingagi standard-library modules in this subsystem.

## `std.app`
Application lifecycle.

## `std.app.plugin`
Engine plugins and lifecycle hooks.

## `std.app.config`
Application and engine configuration.

## `std.window`
Windows, surfaces, and display modes.

## `std.input`
Unified input abstraction.

## `std.input.keyboard`
Keyboard input.

## `std.input.pointer`
Mouse and pointer input.

## `std.input.gamepad`
Gamepads and controllers.

## `std.input.touch`
Touch and multitouch input.

## `std.input.action`
Action maps and semantic input bindings.

## `std.input.gesture`
Gesture recognition.

## `std.display`
Display enumeration and display properties.

## `std.cursor`
Cursor control.

## `std.lifecycle`
Focus, suspend/resume, and shutdown.
