# Editor Tools

Proposed Ingagi standard-library modules in this subsystem.

## `std.editor`
Editor integration APIs.

## `std.editor.scene`
Scene editing and hierarchy.

## `std.editor.property`
Property inspection and editing.

## `std.editor.asset`
Asset browser integration.

## `std.editor.gizmo`
Transform and editing gizmos.

## `std.editor.undo`
Undo/redo commands.

## `std.editor.plugin`
Editor extensions.

## `std.tool`
General developer-tool APIs.

## `std.build`
Build metadata and build integrations.

## `std.shader.compiler`
Shader compilation and validation APIs.

## `std.reflect.schema`
Schema generation and metadata export.
