# Security Crypto

Proposed Ingagi standard-library modules in this subsystem.

## `std.crypto`
Cryptographic interfaces.

## `std.crypto.hash`
Hashing algorithms.

## `std.crypto.digest`
Cryptographic digests.

## `std.crypto.random`
Cryptographically secure random generation.

## `std.crypto.signature`
Digital signatures.

## `std.crypto.kdf`
Key derivation.

## `std.crypto.aead`
Authenticated encryption.

## `std.security`
Security-related primitives and policies.
