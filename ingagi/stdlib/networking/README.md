# Networking

Proposed Ingagi standard-library modules in this subsystem.

## `std.net`
Network abstractions.

## `std.net.ip`
IP addresses and endpoint types.

## `std.net.tcp`
TCP connections.

## `std.net.udp`
UDP sockets.

## `std.net.websocket`
WebSocket client/server support.

## `std.net.http`
HTTP client and server APIs.

## `std.net.tls`
TLS integration.

## `std.net.dns`
Name resolution.

## `std.net.packet`
Packet construction and parsing.

## `std.net.transport`
Transport abstraction.

## `std.net.session`
Session management.

## `std.net.replication`
Network state replication.

## `std.net.prediction`
Client-side prediction.

## `std.net.rollback`
Rollback and resimulation support.

## `std.net.interpolation`
Remote-state interpolation.

## `std.net.serialization`
Network-oriented serialization.
