# Text Serialization

Proposed Ingagi standard-library modules in this subsystem.

## `std.string`
Owned strings and string manipulation.

## `std.string_view`
Non-owning string views.

## `std.text`
Text processing and Unicode utilities.

## `std.utf8`
UTF-8 encoding and decoding.

## `std.unicode`
Unicode normalization and character properties.

## `std.regex`
Regular expressions.

## `std.format`
Structured string formatting.

## `std.scan`
Token scanning and parsing helpers.

## `std.json`
JSON serialization and deserialization.

## `std.yaml`
YAML support.

## `std.toml`
TOML configuration.

## `std.xml`
XML parsing and writing.

## `std.cbor`
Compact binary object representation.

## `std.msgpack`
MessagePack serialization.

## `std.archive`
Archive containers and packaging.

## `std.codec`
Common encoding and decoding utilities.
