# Gameplay Animation Ui

Proposed Ingagi standard-library modules in this subsystem.

## `std.animation`
Animation clips and playback.

## `std.animation.skeleton`
Skeletons and bone hierarchies.

## `std.animation.blend`
Blend trees and blending.

## `std.animation.ik`
Inverse kinematics.

## `std.animation.morph`
Morph targets and blend shapes.

## `std.animation.curve`
Animation curves.

## `std.navigation`
Navigation queries and pathfinding interfaces.

## `std.navigation.navmesh`
Navigation meshes.

## `std.ai`
General gameplay AI utilities.

## `std.ai.behavior`
Behavior trees.

## `std.ai.state_machine`
Finite-state machines.

## `std.ai.planning`
Planning and decision-making.

## `std.ui`
Retained or immediate-mode UI abstractions.

## `std.ui.layout`
Layout systems.

## `std.ui.widget`
UI widgets.

## `std.ui.text`
Text layout and rendering.

## `std.ui.input`
UI input routing.

## `std.localization`
Localized text and resource lookup.

## `std.accessibility`
Accessibility interfaces and metadata.
