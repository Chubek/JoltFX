# System Io Concurrency

Proposed Ingagi standard-library modules in this subsystem.

## `std.io`
I/O abstractions.

## `std.io.file`
File operations.

## `std.io.buffered`
Buffered readers and writers.

## `std.io.stream`
Stream abstractions.

## `std.fs`
Filesystem paths, directories, and metadata.

## `std.path`
Path manipulation.

## `std.env`
Environment variables.

## `std.process`
Process creation and management.

## `std.platform`
Platform identification and capabilities.

## `std.system`
System information.

## `std.library`
Dynamic library loading.

## `std.memory`
Allocation interfaces and memory utilities.

## `std.alloc`
Allocator interfaces.

## `std.time`
Clocks, durations, and timestamps.

## `std.clock`
Monotonic and wall-clock interfaces.

## `std.thread`
Threads and thread lifecycle.

## `std.sync`
Mutexes, condition variables, and atomics.

## `std.task`
Tasks and task execution.

## `std.async`
Asynchronous operations.

## `std.channel`
Message-passing channels.
