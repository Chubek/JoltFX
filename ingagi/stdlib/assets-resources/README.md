# Assets Resources

Proposed Ingagi standard-library modules in this subsystem.

## `std.asset`
Asset handles, metadata, and lifecycle.

## `std.asset.server`
Central asset loading and caching.

## `std.asset.loader`
Format-specific loading interfaces.

## `std.asset.import`
Import pipeline interfaces.

## `std.asset.watch`
Asset change detection.

## `std.asset.bundle`
Bundling and packaging.

## `std.asset.handle`
Typed asset references.

## `std.asset.dependency`
Asset dependency tracking.

## `std.asset.hot_reload`
Development-time reload.

## `std.resource`
General resource management.

## `std.resource.cache`
Resource caches.

## `std.resource.arena`
Arena-based allocation.

## `std.resource.lifetime`
Resource lifetime policies.

## `std.asset.gltf`
Optional glTF asset support.

## `std.asset.png`
Optional PNG asset support.

## `std.asset.jpeg`
Optional JPEG asset support.

## `std.asset.ktx`
Optional KTX texture support.

## `std.asset.ogg`
Optional Ogg audio support.

## `std.asset.wav`
Optional WAV audio support.

## `std.asset.font`
Optional font asset support.
