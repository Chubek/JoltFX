# Ecs

Proposed Ingagi standard-library modules in this subsystem.

## `std.ecs`
Core ECS types and APIs.

## `std.ecs.entity`
Entity IDs, generations, and lifecycle.

## `std.ecs.component`
Component definitions, registration, and metadata.

## `std.ecs.world`
World creation, ownership, and lifecycle.

## `std.ecs.query`
Typed component queries and query filters.

## `std.ecs.system`
System declarations and execution.

## `std.ecs.schedule`
System ordering, stages, and dependencies.

## `std.ecs.command`
Deferred world mutations and command buffers.

## `std.ecs.events`
Typed events and event dispatch.

## `std.ecs.resources`
World-scoped singleton resources.

## `std.ecs.relationship`
Entity relationships and hierarchies.

## `std.ecs.change`
Change detection and dirty tracking.

## `std.ecs.observer`
Reactive observers for world changes.

## `std.ecs.parallel`
Parallel system execution.

## `std.ecs.serialization`
World and entity serialization.

## `std.ecs.snapshot`
Snapshots, restoration, and rollback.

## `std.ecs.replication`
Replication metadata and synchronization.
