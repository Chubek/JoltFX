# Core Runtime

Proposed Ingagi standard-library modules in this subsystem.

## `std.core`
Fundamental types, built-ins, common traits, and language intrinsics.

## `std.types`
Fixed-width integers, floating-point types, and numeric aliases.

## `std.convert`
Explicit conversions and parsing/formatting conversions.

## `std.option`
Optional values and absent-value handling.

## `std.result`
Fallible operations, Result<T, E>, and error propagation.

## `std.error`
Error types, error chains, and diagnostics.

## `std.assert`
Assertions, invariants, preconditions, and postconditions.

## `std.panic`
Panic handling and runtime failure.

## `std.debug`
Debug output, assertions, and inspection helpers.

## `std.reflect`
Type metadata, runtime reflection, field and component introspection.

## `std.any`
Type-erased values and dynamic type handling.

## `std.version`
Engine, language, module, and API version information.
