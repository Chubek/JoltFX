# Collections

Proposed Ingagi standard-library modules in this subsystem.

## `std.collections`
Common collection interfaces.

## `std.array`
Fixed-size arrays.

## `std.slice`
Non-owning contiguous views.

## `std.vector`
Dynamic arrays.

## `std.list`
Linked lists.

## `std.deque`
Double-ended queues.

## `std.stack`
Stack data structure.

## `std.queue`
FIFO queues.

## `std.heap`
Priority queues and heap operations.

## `std.hashmap`
Hash maps.

## `std.hashset`
Hash sets.

## `std.btree`
Ordered trees and maps.

## `std.bitset`
Dense bit sets.

## `std.sparse_set`
Sparse sets, useful for ECS storage.

## `std.ringbuffer`
Ring buffers for audio, streaming, and event queues.

## `std.graph`
Graphs and graph traversal.

## `std.pool`
Object and resource pools.

## `std.intern`
String and symbol interning.
