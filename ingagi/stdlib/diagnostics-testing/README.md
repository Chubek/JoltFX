# Diagnostics Testing

Proposed Ingagi standard-library modules in this subsystem.

## `std.log`
Structured logging.

## `std.trace`
Tracing and spans.

## `std.profile`
CPU profiling.

## `std.gpu.profile`
GPU timing and profiling.

## `std.metrics`
Counters, gauges, and telemetry.

## `std.test`
Unit and integration testing.

## `std.test.property`
Property-based testing.

## `std.test.benchmark`
Benchmarking.

## `std.validate`
Runtime validation.

## `std.diagnostics`
Structured diagnostic reports.

## `std.console`
Developer console.

## `std.inspector`
Runtime inspection.

## `std.gizmo`
Editor and debug gizmos.

## `std.capture`
Frame, image, and trace capture.
